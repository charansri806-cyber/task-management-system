# TaskFlow — Task Management System

A clean, responsive task dashboard for planning and tracking everyday work. This college project demonstrates full CRUD (Create, Read, Update, Delete), task completion, search, filters, sorting, dashboard statistics, an Express REST API, and persistent JSON-file storage.

## Technologies

- HTML5 for accessible page structure
- CSS3 for responsive styling (no CSS framework)
- Vanilla JavaScript for the interactive frontend (no React, Angular, Vue, or other frontend framework)
- Node.js and Express.js for the REST API and static-file server
- JSON file storage in `data/tasks.json`

## Features

- Dashboard counts for total, completed, pending, and high-priority tasks, plus completion percentage
- Create tasks with title, description, due date, priority, and status; edit or delete with confirmation
- Toggle tasks between pending and completed
- Search by title; filter by status or priority; sort by newest, oldest, due date, or priority
- Responsive layout for desktop, tablet, and phones; inline validation and API error feedback
- UUID task identifiers and persistent data across browser refresh and server restarts

## Requirements

Install [Node.js LTS](https://nodejs.org/) (npm is included) and [Visual Studio Code](https://code.visualstudio.com/). Node.js 18 or newer is required. No database server or global npm package is needed.

## Run on Windows using VS Code and PowerShell

1. Download or clone this project to a folder, for example `C:\Users\YourName\Documents\taskflow`.
2. Open VS Code. Choose **File → Open Folder…** and select the `taskflow` folder.
3. In VS Code select **Terminal → New Terminal**. Confirm the terminal is PowerShell and that its current directory is the project folder. If not, run:

   ```powershell
   cd C:\Users\YourName\Documents\taskflow
   ```

4. Install project dependencies once:

   ```powershell
   npm install
   ```

5. Start the application:

   ```powershell
   npm start
   ```

6. Keep the terminal open and visit **http://localhost:3000** in Chrome, Edge, Firefox, or another modern browser. To stop the server, return to the terminal and press **Ctrl+C**. Later, start it again with `npm start`; saved tasks remain in `data/tasks.json`.

For development, `npm run dev` uses Node's built-in watch mode to restart the server when backend files change.

## REST API

All endpoints return JSON. Task objects contain `id`, `title`, `description`, `dueDate`, `priority`, `status`, `createdAt`, and `updatedAt`. `dueDate` is `YYYY-MM-DD` or an empty string; priority is `high`, `medium`, or `low`; status is `pending` or `completed`.

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/tasks` | Return `{ "tasks": [...] }`, newest-created first |
| `GET` | `/api/tasks/:id` | Return `{ "task": {...} }` or 404 |
| `POST` | `/api/tasks` | Create a task; provide JSON fields `title`, `description`, `dueDate`, `priority`, and `status`; returns 201 |
| `PUT` | `/api/tasks/:id` | Replace/update the editable task fields; returns updated task or 404 |
| `PATCH` | `/api/tasks/:id/complete` | Set completion; JSON body: `{ "completed": true }` or `{ "completed": false }` |
| `DELETE` | `/api/tasks/:id` | Delete a task; returns a success message or 404 |

Example PowerShell request:

```powershell
$body = @{ title = "Prepare project demo"; description = "Show CRUD and filters"; dueDate = "2026-12-05"; priority = "high"; status = "pending" } | ConvertTo-Json
Invoke-RestMethod -Uri http://localhost:3000/api/tasks -Method Post -ContentType "application/json" -Body $body
```

Invalid or missing required titles and invalid dates/priorities/statuses return HTTP 400 with `{ "error": "..." }`. Missing task IDs return HTTP 404. Unexpected server errors return HTTP 500. IDs are generated by the server; clients must not assign them.

## Storage and safety

Task data is kept in `data/tasks.json`. Each successful create, update, completion change, or delete writes the updated task array to a temporary file and renames it over the data file. Keep a backup before manually editing or clearing it. The project intentionally has no login or external service credentials. `node_modules/` is recreated by `npm install` and should not be committed.

## Troubleshooting

- **`npm` is not recognized:** Install the Node.js LTS version from nodejs.org, close and reopen VS Code so PATH refreshes, and check `node --version` and `npm --version`.
- **Port 3000 is already in use:** Stop the other program using it, or in PowerShell run `$env:PORT=3001; npm start` and open `http://localhost:3001`.
- **The browser cannot connect:** Make sure `npm start` is still running and the terminal says TaskFlow is listening. Check that the URL uses the same port shown in the terminal.
- **Dependency/module error:** From the project folder run `npm install`, then `npm start` again.
- **Tasks do not appear after a restart:** Confirm `data/tasks.json` exists and contains valid JSON (an empty collection is `[]`). Do not delete the file if you need its task records.
- **API says title is required:** Enter a non-empty task title; leading and trailing spaces are removed.

## Demonstration guide

A concise faculty demonstration: add one high-priority pending task with a due date; add a second task at another priority; show how total/pending/high-priority counts change; search by a few title characters; try the priority and status filters and a sort option; edit the first task; mark it completed and show the completion count and progress percentage; mark it pending again; delete a task and accept the confirmation; refresh the browser and show the remaining data is still there. To demonstrate the backend, open `/api/tasks` in the browser or use the PowerShell POST example above. To demonstrate persistence after a server restart, stop and rerun `npm start` and reload the dashboard.
